# 假实验脚本 v1（草案，待 review）

> 由实现整理而成 —— 每一步都对应功能清单里的编号，跑完即可逐项勾。
> 目的不是"看看能不能跑"，而是**证明这套系统产出的数据可以用来回答研究问题**。
>
> 分两部分：
> - **A 自动部分** —— `backend/scripts/dry_run.py`，一条命令跑完，逐项打绿/红
> - **B 人工部分** —— 只有真人操作才碰得到的（hover、关标签页、拔网线），照下表手动走
>
> 两条条件各跑一遍（B 组已后置，暂只跑 C）。

cd backend && ./.venv/Scripts/python.exe scripts/dry_run.py

## B · 人工部分（浏览器）

这些自动跑不了 —— 要么依赖真实指针事件，要么依赖浏览器生命周期。

> B11–B13(断网/关页/崩溃)原先在这张表里，现在改由 `src/lib/logger.test.ts`
> 注入故障来验：fetch 强制失败、派发 `pagehide`、让新 logger 启动在死掉的那个
> 留下的镜像上。它们保护的是**过期不可补**的日志，每次改动都手工走一遍不可持续，
